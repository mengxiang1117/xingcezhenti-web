## 网页版（Web 应用）

本目录还带一个 Web 版题库（`app.py`），支持按模块/题型浏览、在线作答与判分、官方解析 + AI 解析、随机套卷（含倒计时与交卷计分）等。

### 源码启动

1. 安装依赖（Python 3.10+）：

   ```bash
   pip install fastapi uvicorn pydantic openai pyyaml
   ```

2. 配置 AI 接口（可选，不配也能刷题/看官方解析）：复制 `config-example.yaml` 为 `config.yaml`，填入 `openai.api_key`、`base_url`、`models`

3. 启动：

   ```bash
   python app.py
   ```

4. 浏览器打开 <http://127.0.0.1:8000>

> 首次启动会解析全部 md 生成索引（约 1~2 秒）。AI 解析需在 `config.yaml` 里配置模型密钥；
> 不配置也能正常刷题、看官方解析。

### exe 启动

1. 打包（需先 `pip install pyinstaller`）：

   ```bash
   python build.py
   ```

2. 产物在 `dist/xingcezhenti-web.exe`。解压 `题目.zip`（内含 `01-政治理论` ~ `06-资料分析`、`90-图片`），复制 `config-example.yaml` 为 `config.yaml`（需要 AI 解析时填密钥），连同 `static/`、`config.yaml` 一起放到 exe 同级目录后，双击 exe。

3. 浏览器打开 <http://127.0.0.1:8000>

### 运行生成的文件

启动及刷题过程中，会在 exe / 源码同级目录自动生成以下文件（删除后会自动重建）：

| 文件/目录 | 说明 |
|---|---|
| `question_index.json` | 题库索引缓存，首次启动解析全部 md 后生成，加速下次启动 |
| `ai_cache/` | AI 解析缓存（`{qid}.json`），解析过的题下次直接读缓存、不再调用 AI |
| `progress.json` | 答题进度记录 |
| `exams/` | 随机套卷数据（`{exam_id}.json`） |
